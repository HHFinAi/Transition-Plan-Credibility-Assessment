# Contributing

Describe the investment-research problem, affected route, source/method version and uncertainty. Add a bounded skill or operation only with explicit inputs, outputs, stop conditions and tests. Keep monetary and ecological units explicit. Do not copy proprietary frameworks, employer materials or vendor data. Preserve the separate financial, impact and mandate conclusions.

For code changes, add regression tests for adverse and incomplete inputs, rerun all domain packages when modifying shared code, and document model boundaries. Update `CHANGELOG.md`, source metadata and validation results. Do not assert live investment accuracy on synthetic fixtures or market the project as independently audited. Never add autonomous trading or source-verification claims without an explicit architecture and validation review.
