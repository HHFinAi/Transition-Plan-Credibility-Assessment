# Institutional-quality research: claim-to-control map

**Institutional-quality buy-side research, designed to support tradable investment decisions through a traceable, auditable workflow.** This is a process-design claim, not independent certification, client adoption, audited financial statements, proven alpha or production suitability.

| Claim | Implemented control | Boundary |
|---|---|---|
| Instrument-aware | Mandate, identity, currency and route contracts | Identity and legal terms must be sourced and reviewed. |
| Evidence-backed | Registered locators, dates, scopes and numerical metric references | No automated truth or prose-entailment verification. |
| Reproducible arithmetic | Allowlisted functions, units, input provenance and recomputation | Supplied assumptions may be wrong; vector records require host review at row level. |
| Domain-aware | Specialist prompts and typed domain declarations | Declared assessments are not independently established facts. |
| Reviewable workflow | Dependency gates, versions, archive/invalidation and hash-linked events | Local hashes are not tamper-proof if an attacker can rewrite all records/code. |
| Investable handoff | Quote/contract evidence, declared checks and entry/downside fields | No broker, liquidity guarantee, verified legal access or autonomous trading. |
| Accountable review | Human attestation and recorded rationale | No authenticated identity or enforced reviewer independence. |

## Scope
Target validation does not establish financial attractiveness or future delivery. SBTi V2.0 publication and the opening of target validation are different events. Do not turn a credibility rubric into a probability of success.

## Production requirements outside this release
Firm access/identity controls, document/source licensing, PII/MNPI handling, comprehensive retention, backups, dependency and host security reviews, real-document extraction evaluation, independent financial/legal/scientific review, model monitoring, and execution controls are not supplied by this prototype. No external communications or execution integrations are embedded.
