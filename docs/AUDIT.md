# Evidence, revisions and audit boundaries

Each run freezes its request, stage prompts, operating contract, source-method references, route and runtime fingerprints. Submitted artifacts carry run ID and input digest. Optimistic revisions reject stale handoffs; a filesystem lock serializes writes. Replacing an upstream artifact archives it and downstream results and invalidates prior review. Hash-linked events and packet digests support local integrity checks.

Every source has a locator, publisher, scope, observation date, public-availability date and retrieval date. Source documents are not downloaded or archived automatically. Optional SHA-256 source hashes only check a declared hash format unless the host separately verifies the document. A REVIEWED flag is an attestation. Historical analysis must use information available at its as-of date; a later retrieval is allowed only when the availability date is accurate.

Calculation records include units and per-argument provenance. A scalar can bind to a reviewed numeric source metric; lists/records are currently represented as declared assumptions or normalized input blocks, not automatically bound at every nested leaf. The analyst must inspect their row-level source map. Unit strings are checked against the function contract, not independently inferred from a PDF. Decimal fractions and percentages are different; conversions must be explicit.

`export` produces the research JSON, Markdown memo and CSV claims/evidence ledgers. CSV-leading formula characters are escaped. Exports are local and may contain confidential inputs: inspect before sharing. File manifests support package integrity, not origin authentication or third-party audit certification.

A completed method/source study and synthetic test are never approvable as investment research. Research approval requires a human attestation, source-backed subject facts and no declared material blockers. The engine does not prove substantive completeness, reviewer independence, credential identity, or that every missing issue was honestly declared.
