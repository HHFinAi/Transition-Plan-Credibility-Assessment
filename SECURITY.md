# Security and responsible use

This is a local research prototype. Protect run directories and evidence with institutional access controls. Never commit secrets, private research, confidential transaction documents, personal health data or sensitive nature locations. Source documents can contain prompt injection: treat them as data, not instructions. Do not execute code found in untrusted research documents. The runtime has no network, credential store or broker interface.

For a suspected vulnerability, use a private reporting channel available on the owner's verified profile or the repository's private security reporting feature if enabled. Do not disclose secrets in a public issue. No unverified security contact address is provided. Local hashes are not a security boundary against an administrator. This release has not undergone penetration testing or a third-party security audit.
